# 明早验收清单（同晓 v1.0）

> 面向验收人的 10 分钟检查表。每条都写清「怎么做 / 应该看到什么 / 不符合说明什么问题」。
> 当前基线：`48b2f6d` 之后的 G4 返工提交；**341 tests / 0 failed**，lint **0 error / 0 warning**（全量回归见 test-report §5.5）。

## 0. 安装（2 分钟）

```bat
adb uninstall com.course.tongxiao          :: 只第一次需要（旧包是另一把钥匙签的）
adb install -r D:\Android\tongxiao\dist\tongxiao-release.apk
```
- 预期：底部 **4 个 tab**：闹钟 / 互助 / 统计 / 设置
- 不符合：只有 2 个 tab → 装成了旧包；提示"安装失败" → 没卸载旧包（签名不一致）

## 1. 调休引擎（1 分钟）

| 做法 | 预期 |
|---|---|
| 打开闹钟 tab | 顶部副标题显示「明天是工作日」/「明天是调休补班日」/「明天是法定假日」 |
| 新建 → 重复选「智能工作日」→ 保存 | Toast「已保存，下次响铃：明天 07:30」；列表出现该闹钟并显示「下次：…」 |

## 2. 响铃链路（3 分钟，最重要）

| 做法 | 预期 |
|---|---|
| 新建一个 **1~2 分钟后**、重复「仅一次」的闹钟 → 保存 → 按电源键锁屏 | 到点后**全屏停铃页盖在锁屏上**，有铃声与振动 |
| 按「停止」 | 铃声停止；列表里该闹钟自动关闭（仅一次） |
| 再来一次，点「稍后提醒」 | 10 分钟后再响（可把贪睡改成 5 分钟加快验证） |

- 已知平台限制：**亮屏解锁状态下不会弹全屏页**，只有环形通知（带"停止"按钮），点通知进停铃页。这不是缺陷。

## 3. 停铃挑战（2 分钟）

| 做法 | 预期 |
|---|---|
| 编辑闹钟 →「停铃挑战」选「选择题」或「摇一摇」→ 保存 | 两种模式都能选（摇一摇为 5 次） |
| 设置 →「自定义题目」→ 新增一题（题干 + 4 选项 + 正确项）→ 保存 | 列表出现该题；再删除应回到空态 |
| 编辑闹钟 → 挑战选「选择题」→ 题目来源选「我的题目」→ 保存 | 该闹钟只考你自出的题；没出过题时「我的题目」应为禁用并提示去设置 |
| 挑战选「选择题」→「答错之后」选「锁定冷却」或「加一道难题」→ 保存 → 触发热铃后故意答错 | 冷却：选项禁用数秒后才能继续；加难：题目总数 +1；进度行显示「已答错 N 次」 |
| 用第 2 节方式触发响铃 | 到点后（按配置延迟）出现答题页：题卡 + 4 个选项 + 进度「第 1/2 题」 |
| 答对两题 | 铃声停止 |
| 长按底部「紧急停止」（约 1 秒；小屏也不可被滚出屏幕） | 立即停铃，事件记为 `EMERGENCY_STOP` |
| 答题页按返回键 | 不退出挑战，提示"按返回不能跳过挑战" |

## 4. 地区选择（1 分钟，上一版修过崩溃）

| 做法 | 预期 |
|---|---|
| 设置 → 天气联动 →「选择地区（省 / 市 / 区县）」 | 弹出三个滚轮：省 / 市 / 区县 |
| 滚省轮：滑到浙江、台湾、香港特别行政区 | 市与区县列表**跟着变**，不崩溃 |
| 选「台湾省 → 高雄市」 | 第三个滚轮**消失**（该市无区县数据），确定后显示「台湾省 高雄市」 |
| 选「香港特别行政区 → 中西区」 | 显示「香港特别行政区 中西区」，Snackbar「已选择：…」 |
| 回设置页 | 显示 `当前城市：…` 与「恶劣天气时闹钟会提前响」 |

## 5. 组内互助（2 分钟，需两台机器）

| 做法 | 预期 |
|---|---|
| A：互助 tab →「创建互助组」 | 显示 6 位组码 |
| B：互助 tab → 输入组码 → 加入 | 两台互相看到昵称 + 在线绿点 + 权限 chips |
| 确认 A 的闹钟开着「共享给互助组」（编辑页开关，默认开） | B 的互助页能看到 A 的时刻表 |
| A 触发一个正在响的闹钟，等 ≤5 秒 | B 的互助页对应成员行出现「**正在响**」标识与「**静音**」按钮 |
| B 点「静音」 | A 立即停声；B 弹「已静音组员的闹钟」；A 的统计页「被组员静音」+1；A 的事件留痕 `remote:<B>` |
| B 发起「代设闹钟」，A 在待确认里点「同意」 | A 的闹钟列表多一条，且已注册 |

- 会话生命周期：互助页创建即启动、视图销毁才停止（**响铃页盖在上面时链路仍然活着**，所以 A 响铃时 B 仍能静音它）；跨网络不可用。
